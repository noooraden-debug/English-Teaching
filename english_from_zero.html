تفعيل صوت عربي على جهازك

لا يستطيع ملف HTML تثبيت صوت النظام من تلقاء نفسه. أضف بيانات النطق العربية مرة واحدة من إعدادات جهازك، ثم ارجع واضغط «تحديث الأصوات».
  1. Android: الإعدادات ← النظام أو الإدارة العامة ← تحويل النص إلى كلام. اختر «Speech Services by Google»، ثم «تثبيت بيانات الصوت» ← العربية. بعد التنزيل أعد فتح التطبيق.
  2. iPhone / iPad: الإعدادات ← تسهيلات الاستخدام ← المحتوى المنطوق ← الأصوات ← العربية، ثم نزّل الصوت. ارجع إلى Safari واضغط «تحديث الأصوات».
  3. Windows: الإعدادات ← الوقت واللغة ← الكلام ← إدارة الأصوات أو إضافة أصوات ← العربية، ثم أعد فتح المتصفح.
  4. Mac: إعدادات النظام ← تسهيلات الاستخدام ← المحتوى المنطوق ← صوت النظام ← إدارة الأصوات ← العربية.

قد تختلف أسماء القوائم حسب إصدار النظام. الأصوات نفسها يوفّرها الجهاز أو المتصفح؛ عند غياب صوت عربي لن نحاول قراءة العربية بصوت إنجليزي غير مفهوم. بعد تنزيل الصوت، استخدم «تحديث الأصوات» ثم جرّب زر الاستماع.
