# إنجليزي من الصفر — حزمة التطبيق

## الملفات
| الملف | الوظيفة |
|---|---|
| `english_from_zero.html` | التطبيق كاملًا في ملف واحد (الدروس + الخطوط + البرمجة). يفتح بالنقر المزدوج. |
| `index.html` | نسخة مطابقة تمامًا، باسم يطلبه المستضيف افتراضيًا. |
| `manifest.webmanifest` | بطاقة تعريف التطبيق (الاسم، الأيقونة، وضع standalone). |
| `sw.js` | خدمة العمل دون اتصال (تُخزّن الملفات بعد أول زيارة). |
| `icon-192.png` · `icon-512.png` · `apple-touch-icon.png` | أيقونات الشاشة الرئيسية. |

> ملف HTML وحده لا يستطيع تثبيت نفسه كتطبيق. التثبيت يحتاج **رابط HTTPS** يقدّم هذه الملفات معًا.
> بعد التثبيت يمكنك فتح التطبيق من أيقونته على الشاشة الرئيسية دون الرجوع إلى الملف، ودون إنترنت.

## أسرع طريقة للنشر (٥ دقائق، مجانًا)
1. اضغط الملفات الستة في مجلد واحد (أو استخدم مجلد المشروع كما هو).
2. افتح **app.netlify.com/drop** واسحب المجلد إلى الصفحة (لا يحتاج حسابًا للتجربة).
3. ستحصل على رابط مثل `https://xxxx.netlify.app` — افتحه على الهاتف.
4. **Android / Chrome:** قائمة ⋮ ← «تثبيت التطبيق» (أو زر «تثبيت» أعلى التطبيق).
   **iPhone / iPad:** Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
   **Windows / Mac (Chrome أو Edge):** أيقونة التثبيت في شريط العنوان ← «تثبيت».
5. افتح التطبيق مرة واحدة على الإنترنت حتى يظهر «جاهز للعمل دون اتصال»، وبعدها يعمل بلا إنترنت.

بدائل للنشر: GitHub Pages، Cloudflare Pages، Vercel — أي استضافة ثابتة تخدم HTTPS.

### تجربة على الشبكة المنزلية فقط
من داخل المجلد: `python3 -m http.server 8000`
ثم افتح `http://عنوان-جهازك:8000` من الهاتف على نفس الشبكة.
(التثبيت الكامل قد لا يعمل على HTTP غير الآمن، لكن التطبيق نفسه يعمل.)

## الصوت العربي
- التطبيق يستخدم أصوات النظام. وجود صوت عربي يعني شرحًا منطوقًا كاملًا.
- الأفضل صوتًا: **Edge أو Chrome على الحاسوب** (أصوات Natural/Online).
- إن لم يوجد صوت عربي: يعمل التطبيق تلقائيًا بـ **الوضع المقروء** — يعرض الشرح مكتوبًا سطرًا بسطر مع نطق الأمثلة الإنجليزية بصوت إنجليزي، مع زر «التالي».
- يمكنك تغيير هذا السلوك من: الإعدادات ← «عند غياب الصوت العربي».
- طرق إضافة صوت عربي: الإعدادات ← الوقت واللغة ← الكلام (Windows) / تحويل النص إلى كلام (Android) / تسهيلات الاستخدام ← المحتوى المنطوق (iOS، macOS).

## ملاحظات
- التقدّم (الدروس، النقاط، دفتر الأخطاء، الإعدادات) محفوظ في متصفح جهازك.
- تحديث الملفات: استبدل `index.html` بنسخة أحدث ثم أعد فتح التطبيق مرتين لتحديث الذاكرة المؤقتة.
